## חלק ב' — מה נשאר לך לעשות (חוסמים)

### 1. לכבות את מצב הבדיקה של WhatsApp

כל עוד `WHATSAPP_TEST_MODE=true`, הודעות נשלחות **רק** ל-`WHATSAPP_TEST_PHONE`.
כל שאר הלקוחות לא מקבלות דבר — בשקט, בלי שגיאה. זה הפער מספר 1.

לעשות רק **אחרי** חזרה יבשה מלאה (חלק ג'):

```bash
npx vercel env rm WHATSAPP_TEST_MODE production
# שימו לב: הפקודה נוטה להסיר גם את היעד Preview — לבדוק אחריה עם env ls
```

אימות:

```bash
curl -s -H "Authorization: Bearer $CRON_SECRET" \
  https://app.allura.info/api/health | jq .config
# מצופה: whatsAppTestMode=false, realWhatsAppSend=true
```

### 2. טוקן Meta קבוע

טוקן משתמש רגיל פג אחרי 60 יום, וכשזה קורה ההודעות מפסיקות להישלח באמצע
החודש (זה כבר קרה — שגיאה 190). לוודא ש-`META_WHATSAPP_ACCESS_TOKEN` בפרודקשן
הוא טוקן של **System User** ללא תפוגה (Meta Business Settings → System Users →
Generate Token).

### 3. Meta App במצב Live ותבניות מאושרות

- [ ] האפליקציה ב-Live ולא ב-Development
- [ ] תבניות תפעוליות ב-APPROVED: אישור תור, תזכורת, `business_new_booking_he`
- [ ] Webhook רשום ל-`https://app.allura.info/api/whatsapp/webhook`, מנוי לאירועי סטטוס
- [ ] המספר המחובר אינו מספר בדיקה של Meta (`+1 555…`)

### 4. גיבוי מסד נתונים — ולוודא שחזור

זה המקום היחיד שאין ממנו דרך חזרה.

- [ ] Neon → Point-in-time restore פעיל, לדעת כמה ימים אחורה
- [ ] **לבצע שחזור ניסיון אחד** לענף נפרד. גיבוי שלא נבדק אינו גיבוי
- [ ] להריץ גיבוי ידני ממש לפני האונבורדינג הראשון

### 5. לחבר את ערוץ ההתראות

הקוד מוכן; חסר היעד. הכי מהיר: תרחיש Make עם Webhook שמעביר לוואטסאפ/מייל שלך.

```bash
npx vercel env add ERROR_ALERT_WEBHOOK_URL production
```

מבנה ה-JSON שנשלח: `{ scope, message, stack, context, env, time, text }` —
השדה `text` הוא משפט מוכן להצגה.

### 6. ניטור זמינות חיצוני

- [ ] UptimeRobot / Better Uptime על `https://app.allura.info/api/health` כל 5 דקות
- [ ] התראה לטלפון על 503 או על אי-מענה
- [ ] `/api/health` מחזיר 503 כשמסד הנתונים לא מגיב — זה מה שהמוניטור צריך לתפוס

### 7. לוודא שה-crons באמת רצים

ב-[vercel.json](../vercel.json) מוגדרות 6 משימות בתדירות שעתית. **תוכנית Hobby
של Vercel מגבילה crons** (מעטים, פעם ביום) — ואז התזכורות, החזרת הלקוחות,
הנאמנות והקמפיינים פשוט לא רצים, בלי שום סימן באפליקציה.

- [ ] לוודא שהפרויקט ב-Pro
- [ ] Vercel → Crons: כל 6 המשימות רצות ומחזירות 200 (401 = `CRON_SECRET` שגוי)

### 8. שם הישות המשפטית

```bash
npx vercel env add NEXT_PUBLIC_LEGAL_ENTITY_NAME production
# הערך: שם העוסק המורשה / החברה שמפעילה את Allura
```

מוצג בתחתית העמודים הציבוריים ובמסמכים המשפטיים. `checkEnv` מזהיר עליו בעלייה.

### 9. תיבת התמיכה חייבת לקבל דואר

`support@allura.info` מופיעה בתנאי השימוש, במדיניות הפרטיות, בעמוד יצירת קשר
ובמסך הקריסה. Resend מאומת ל**שליחה** — לוודא שיש תיבה/העברה שבאמת **מקבלת**.

### 10. חשבוניות על המנוי

להחליט ולהגדיר מי מנפיק חשבונית מס/קבלה על כל חיוב חודשי — Grow או רואה
החשבון. אין חיוב בכרטיס בלי מסמך.

בנוסף: להחליט אם המחיר המוצג (199 ₪) כולל מע"מ, ולציין זאת במפורש במסך
הפעלת המנוי ובתנאי השימוש.

### 11. סקירה משפטית

תנאי השימוש נכתבו כך שישקפו במדויק את מה שהקוד עושה, אבל הם לא נכתבו בידי
עורך דין. לפני חיוב אמיתי — לתת לעורך דין לעבור על סעיפי החיוב, הביטול,
ההחזרים והגבלת האחריות.

## חלק ג' — חזרה יבשה לפני הלקוחה הראשונה

לבצע מקצה לקצה על עסק דמו (`npm run db:demo`), עם `WHATSAPP_TEST_MODE=true`
והטלפון שלך כ-`WHATSAPP_TEST_PHONE`:

1. הרשמה של בעלת עסק חדשה
2. תשלום אמיתי דרך Grow — ולוודא שנוצרה שורה ב-`SubscriptionCharge` וב-`/admin/subscriptions`
3. הגדרת שירותים, שעות פעילות ופרטי עסק
4. הזמנה מדף ההזמנות הציבורי → לוודא שהתראה הגיעה אליך
5. אישור התור → הודעת אישור מגיעה
6. הרצת cron התזכורות ידנית → תזכורת מגיעה
7. סימון "הושלם" → הודעת תודה נשלחת מיד
8. ביטול מנוי מההגדרות → החיוב המתחדש נעצר ב-Grow
9. הורדת שני קובצי הייצוא ופתיחתם ב-Excel — לוודא עברית תקינה

## חלק ד' — נוהל מחיקת נתונים

התחייבות: מחיקה מלאה תוך 30 יום מאימות הבקשה.

1. לאמת שהבקשה הגיעה מבעלת החשבון (מהמייל הרשום).
2. לוודא שהיא ייצאה את הנתונים (הגדרות → הנתונים שלך), או לייצא עבורה.
3. תצוגה מקדימה של מה יימחק:
   ```bash
   npx tsx --env-file=.env.production scripts/delete-business.ts <slug>
   ```
4. מחיקה בפועל:
   ```bash
   npx tsx --env-file=.env.production scripts/delete-business.ts <slug> --confirm
   ```
   להוספת מחיקת חשבון המשתמשת עצמה: `--with-user` (נמחק רק אם אין לה עסק נוסף).
5. לתעד את מועד הביצוע ולהשיב לפונה.

תיעוד חיובים (`SubscriptionCharge`) נשמר לצורכי חשבונאות ומס — כפי שנכתב
במדיניות הפרטיות.

- שיחה קצרה עם בעלת העסק באמצע השבוע — הסימן האמיתי היחיד
